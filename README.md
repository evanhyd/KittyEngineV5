# KittyEngineV5
A high-performance C++ bitboard chess engine built with compile-time template metaprogramming optimizations.

## Authorship
- Coded and debugged with the assistance of AI.
- Traiend with jw1912/bullet.
- Dataset from HugginFace (Stockfish + LC0).

## CLI Usage

```text
Usage: KittyEngine [options]

Options:
  --type <hce|nnue|noop>                Evaluation policy: hce, nnue (default), noop
  --mode <bullet|blitz|rapid|classical> TT size: bullet=64MB, blitz=256MB, rapid=1GB (default), classical=2GB
  --search_config <path>                Search configuration YAML file (default: search_config.yaml)
  --help, -h                            Print CLI help and exit
```

## Features & Optimizations

### Board & Move Generation
- 64-bit bitboard representation.
- Plain magic bitboards for sliding piece attacks.
- Compile-time node specialization via template metaprogramming.
- Templated legal move generation.
- Incremental Zobrist hashing and evaluation updates.

### Transposition Table
- Two-tier clustered replacement with depth preference, aging, and PV protection.
- Caches best move, score, bound type, depth, static eval, and check status.

### Search (`NegamaxSearchPolicy`)
- Principal Variation Search (PVS) with iterative deepening.
- Aspiration windows.
- In-check search extensions.
- In-place triangular PV table.
- Repetition and 50-move draw detection.
- In-place staged move picker.
- Static Exchange Evaluation (SEE).
- History heuristics:
  - Butterfly quiet history with gravity aging
  - 1-ply continuation / refutation history
  - 2-ply followup history
  - Piece-to-victim capture history
  - Killer moves (2 slots per ply)
  - Improving heuristic
- Pruning and reductions:
  - Adaptive null-move pruning
  - Reverse futility pruning
  - Futility pruning
  - SEE pruning
  - Late move pruning (LMP)
  - Late move reductions (LMR)
  - Quiescence search
- Runtime YAML search configuration (`--search_config`).

### Evaluation
- **NNUE**:
  - HalfKA architecture with SCReLU activations.
  - Incremental accumulator updates with deferred king refreshes.
  - SIMD matrix operations.
  - Trained on dataset generated by **LC0**.
  - Weights loaded from `weights.bin`.
- **Handcrafted Evaluation**:
  - Tapered evaluation.
  - Material values, piece-square tables, mobility, pawn structure, and king safety.

### Time Management
- `EqualPercentageTimeControlPolicy`: Dynamic move time allocation based on clock and increment.

## UCI Commands

| Command | Action |
| --- | --- |
| `uci` | Print engine identification and `uciok`. |
| `isready` | Reply with `readyok`. |
| `ucinewgame` | Reset search, TT, and evaluation state for a new game. |
| `position startpos [moves <move> ...]` | Set the starting position and play moves. |
| `position fen <FEN> [moves <move> ...]` | Set a custom FEN position and play moves. |
| `go depth <N>` | Search up to depth `N`. |
| `go movetime <ms>` | Search with a fixed time budget. |
| `go wtime <ms> btime <ms> [winc <ms>] [binc <ms>] [movestogo <N>]` | Search with clock times and increments. |
| `quit` | Exit the engine. |
| `play <move>` | Play a move directly on the board (terminal extension). |
| `perft depth <N> [detail]` | Run perft move path enumeration test. |
